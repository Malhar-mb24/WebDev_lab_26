# WebDev_lab_26

A collection of standalone HTML pages created as part of web development labs and practice. Each page can be opened directly in a web browser; the repository currently has no build step or package dependencies.

## File index

| File | Purpose | Description |
| --- | --- | --- |
| `lab1.html` | HTML basics lab | Demonstrates common HTML elements, including headings, paragraphs, line breaks, quotations, preformatted text, and text formatting. |
| `resume.html` | Resume page | A personal resume-style page with sections for skills, experience, education, certifications, projects, and additional information. |
| `timetable_lab2.html` | Timetable lab | Displays a weekly class timetable using an HTML table and embedded CSS styling. |
| `README.md` | Project guide and file index | Describes the repository and provides this editable index of its files. |

When adding or renaming a project file, update this table with its filename, purpose, and a short description.
